# 截图伪装 (ScreenshotFaker)

简体中文 | [English](README.md)

---

## 📖 项目简介

**截图伪装 (ScreenshotFaker)** 是一个支持用户在截屏中保护个人隐私的软件，并且具有很强的反检测能力。

它允许用户通过自定义的方式在 截屏、录屏和屏幕共享 中保护个人隐私不被“不安分”的应用恶意获取。

---

## ✨ 特点

- **保护截屏获取到的隐私内容**  
  防止截图服务获取到屏幕中的敏感内容，并支持用户替换为自定义图片  
  防止录屏服务及其它类似功能获取敏感内容，支持替换为自定义的视频流（本地或网络）  
  支持设置特定的自由浮窗不被截录屏捕获  
  支持将允许截屏的敏感APP设置为不可截屏

- **全面地屏蔽特定软件的恶意检测**  
  让用户的截录屏事件跳过应用的恶意截录屏检测  
  支持独立地屏蔽应用的悬浮窗检测，焦点检测和窗口完整性检测  
  对于“不安分”的恶意软件，支持更加激进的检测过滤功能

- **无痕的截录屏以及屏幕共享**  
  截录屏功能通过系统底层的直接调用绕过应用层的恶意检测  
  屏幕共享不仅可以局域网共享，也支持通过SSH远程共享  
  同样支持高效地接收屏幕共享和远程控制

- **自定义操作方式**  
  绝大部分配置供用户自定义选择  
  支持通过匹配 系统日志 触发截录屏以及屏幕共享，不局限于传统的截录屏手势  
  通过配置模板高效地配置和管理每个应用

- **极致的隐藏性支持**  
  支持在悬浮窗中查看截录屏文件且不会被截屏捕获  
  支持在最近任务中隐藏此应用  
  支持隐藏桌面图标并通过稳定的方式重新打开  
  支持以自定义的包名和软件特征重新安装  
  支持在卸载此软件后，仍然可以完成截录屏以及屏幕共享功能

- **极致的隐私性保护**  
  所有配置采用强加密方案存储  
  支持页面保护防止配置被截屏泄露  
  截录屏文件支持自动高强度加密  
  文件名支持全随机（随机的字符和长度）  
  端口通信全程高强度加密  
  问题反馈的数据传输采用动态端到端加密

- **极致的反胁迫保护**  
  支持应用内密码与胁迫密码，胁迫触发硬件密钥销毁，数据即刻永久失效  
  强制启用超时自毁设置，在自定义的时间内未正常使用即判定胁迫并自毁数据  
  内置防篡改保护，任何非法的数据注入或修改即判定异常并自毁数据

- **更多特性持续开发中...**

## ⚙️ 权限依赖

本项目功能主要依赖 **LSPosed**、**Shizuku** 实现：

**LSPosed**
- 保护截录屏获取到的隐私内容
- 在不允许截屏的页面截屏
- 在允许截屏的页面禁止截屏
- 屏蔽特定软件的截录屏检测
- 屏蔽特定软件的悬浮窗检测
- 屏蔽特定软件的焦点检测，悬浮窗检测和窗口完整性检测
- 设置特定应用的小窗实现截图穿透

**Shizuku**
- 无痕的截录屏以及屏幕共享
- 通过匹配 系统日志 触发截录屏以及屏幕共享
- 卸载此软件后，仍然完成截录屏以及屏幕共享功能

**Root**
- 与 Shizuku 功能一致，**但隐藏性更强**
- 悬浮窗无法被下层应用检测和屏蔽

**无特权**
- 接收来自此应用的屏幕共享
- 应用内密码与胁迫密码
- 硬件级和软件级的文件强加解密
- 在悬浮窗中查看截录屏文件且不会被截屏捕获
- 在最近任务中隐藏此应用
- 隐藏桌面图标并通过稳定的方式重新打开
- 以自定义的包名和软件特征重新安装
