# 截图伪装 (ScreenshotFaker)

简体中文 | [English](README.md)

---

## 📖 项目简介

**截图伪装 (ScreenshotFaker)** 是一个支持用户在截屏中保护个人隐私的软件，并且具有很强的反检测能力。

它允许用户通过自定义的方式在 截屏、录屏和屏幕共享 中保护个人隐私不被“不安分”的应用恶意获取。

---

## ✨ 特点

- **保护截屏获取到的隐私内容**  
  防止截图服务获取到屏幕中的敏感内容，并支持用户自定义遮挡方式  

- **屏蔽特定软件的截屏检测**  
  让用户的截图事件跳过应用的恶意截图检测

- **无痕的截录屏以及屏幕共享**  
  通过系统底层的直接调用绕过应用层的恶意检测

- **自定义操作方式**  
  支持通过匹配 系统日志 触发截录屏以及屏幕共享，不局限于传统的截录屏手势

- **极致的隐藏性支持**  
  支持在卸载此软件后，仍然可以完成截录屏以及屏幕共享功能

- **极致的隐私性保护**  
  绝大部分配置供用户自定义选择，文件名支持全随机，端口通信全程高强度加密

- **功能全面的屏幕共享**  
  不仅可以接收屏幕共享和开启局域网共享，也支持通过SSH远程共享

- **更多特性持续开发中...**

## ⚙️ 技术依赖

本项目功能主要依赖 **LSPosed**、**Shizuku** 实现：  

**LSPosed**
- 保护截屏获取到的隐私内容
- 屏蔽特定软件的截屏检测

**Shizuku**
- 无痕的截录屏以及屏幕共享
- 通过匹配 系统日志 触发截录屏以及屏幕共享
- 卸载此软件后，仍然完成截录屏以及屏幕共享功能  

**Root**
- 已 Root 的用户可直接授予 Root 权限，与 Shizuku 功能一致，**二选一即可**
